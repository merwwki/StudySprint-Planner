# StudySprint Planner — Mockup
[View PDF](assets/StudySprint%20Planner%20—%20Mockup.pdf)
## Overview

The StudySprint Planner mockup presents the visual design of an academic task planner intended to help students organize assignments and deadlines. The interface emphasizes clarity, consistency, and ease of use.

The design covers the login screen, task dashboard, task form, empty state, and mobile layout.

## Login Screen

The login screen introduces the application and provides access through its configured login mechanism. It uses a clear heading, concise supporting text, appropriately labeled inputs, and a prominent login button.

Error messages are displayed when authentication fails, and loading feedback is provided while a login request is being processed.

## Task Dashboard

The dashboard is the primary workspace for managing academic tasks. It displays saved tasks in an organized layout and provides access to the main task-management actions.

Each task displays its available information, including its title, subject, due date, priority, and completion status. Actions for editing, deleting, and updating completion status are presented clearly.

Example tasks include:

- Finish Database Assignment
- Review Project Management Notes
- Complete Programming Activity
- Review Previous Lessons

These examples represent sample academic tasks used to illustrate the interface.

## Add and Edit Task Form

The task form provides fields for the task title, subject, description, due date, and priority. A clear save action allows users to submit the form, while a cancel action allows them to leave without saving.

Validation feedback communicates when required information is missing or invalid.

The same form layout is used when creating a new task and editing an existing task.

## Empty State

The empty state appears when there are no tasks to display. It explains that the task list is empty and provides a clear action for creating the first task.

The layout follows the same visual style as the dashboard to maintain consistency.

## Mobile Layout

The mobile layout adapts the dashboard, login screen, and task form to narrow screens. Content is arranged vertically where appropriate, controls remain accessible, and text stays readable without horizontal overflow.

Buttons and form fields are designed to remain usable with touch input.

## Visual Design

The interface uses consistent typography, spacing, component styling, and color contrast. Headings establish a clear hierarchy, while task details and actions are arranged to support quick scanning.

Priority and completion states are distinguishable through visible labels or indicators rather than color alone.

## Design Consistency

All screens follow the same design principles and component styles. The login form, task form, buttons, task items, input fields, and feedback messages use consistent spacing and interaction patterns.

The mockup represents the application's intended visual presentation and should remain consistent with the functionality included in the implemented application.
